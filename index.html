    BYTE Challenge '26 Bug Tracker (10/10 Fixed)

    CC-01FIXED
    The search suggestions are behind everything
    "I start typing a dish name and the list of suggestions comes up, but it's stuck behind the rest of the page. I can only click the very top bit of it."
    Cause: .search-wrap had z-index: 1 while .cat-tabs below it had z-index: 40.
    Fix: Elevated .search-wrap to z-index: 50 in style.css.
    CC-02FIXED
    Can't read anything in dark mode
    "I switched the site to dark mode and now the dish names and the prices are almost invisible."
    Cause: .dish-body had hardcoded color: #2b2118 overriding theme CSS variable.
    Fix: Switched to color: var(--ink); for high-contrast cream text in dark mode.
    CC-03FIXED
    The menu is wider than my phone
    "I have to scroll sideways to see the whole menu, and the Add to Cart buttons on the right-hand dishes are cut off the edge of the screen"
    Cause: .name-btn had width: max-content; on small screens, blowing past grid column widths.
    Fix: Bound .name-btn to width: 100%; max-width: 100% and added min-width: 0.
    CC-04FIXED
    The buttons don't work on my tablet
    "Add to Cart does nothing. The star to save a dish does nothing either. The buttons look completely normal... Only my tablet?"
    Cause: Between 761px and 900px, .dish-card::after overlay sat over buttons with z-index: 3.
    Fix: Added pointer-events: none; so touch/click events pass straight through.
    CC-05FIXED
    The category bar scrolls away on my phone
    "On smaller screens, the category and filter bar scrolls away instead of staying visible at the top while I scroll down..."
    Cause: .view { overflow-x: hidden; } creates a scroll context that invalidates position: sticky.
    Fix: Changed to overflow-x: clip; in style.css.
    CC-06FIXED
    I ordered more than they had
    "The counter says only 2 samosas were left but it let me order 5, and the order went through fine."
    Cause: validateLine only checked stock <= 0 without checking qty > stock, and reserveStock subtracted unchecked.
    Fix: Enforced remaining stock check in validateLine and reserveStock in logic/validation.js.
    CC-07FIXED
    Cancelling makes it worse
    "A student cancelled an order and the number of plates we have left went down again instead of coming back."
    Cause: releaseStock() used dish.stock - line.qty instead of + line.qty.
    Fix: Changed subtraction to addition in logic/validation.js.
    CC-08FIXED
    An old coupon still works
    "FRESHERS24 was last year's offer and it expired ages ago. Someone used it yesterday and got the discount?!!"
    Cause: applyCoupon() in logic/pricing.js never verified coupon.expiresAt < now.
    Fix: Added expiration check returning reason: 'This coupon has expired'.
    CC-09FIXED
    The menu shows more dishes than it should
    "The page is supposed to show a few dishes at a time and load more as you scroll. It just dumps a much longer list straight away!"
    Cause: paginate() computed items = list.slice(start, start + perPage), but returned items: list.
    Fix: Returned items in logic/search.js.
    CC-10FIXED
    Sorting by price is backwards
    "I picked 'price: low to high' and the most expensive things came first. I tried the other option and that gave me the cheap ones."
    Cause: Comparators in SORTERS['price-asc'] and ['price-desc'] were swapped.
    Fix: Set price-asc: a.price - b.price and price-desc: b.price - a.price.
